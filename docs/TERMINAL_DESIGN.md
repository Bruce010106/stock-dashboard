# 专业暗色终端界面规范（方向 B）

2026-10-15 用户在三个候选方向中选定 B：专业暗色终端，暗色为默认，保留日间切换。
本规范取代 `LIQUID_GLASS_DESIGN.md` 的浅色玻璃方向。

## 参考来源（联网检索，2026-10-15）

- Kombai 画廊「Cockpit」期货终端：深色底、红绿买卖信号、琥珀强调，Inter 文本配 JetBrains Mono 数字，订单簿侧栏与 K 线并排。
- Kraken Pro、OKX：可调整面板、并排信息区（adminlte.io 交易看板案例整理）。
- Bloomberg Terminal：高密度但隐藏复杂度，依赖一致的快捷键流程（Bloomberg 官方文章、Matthew Ström 关于 UI 密度的文章）。
- Linear 风格：单一强调色、颜色只表达语义、小号紧凑行、Ctrl+K 命令入口。

以上为设计方向参考，本项目未复制其中任何具体产品的界面或素材。

## 视觉规则

- 平面：纯色背景与面板、1px 细边框、4–6px 小圆角；不使用渐变、玻璃、阴影或背景模糊。
- 单一强调色：琥珀色（夜间 `#f0a43a`，日间 `#c77700`），只用于品牌字、焦点、选中页签和选中态。
- 颜色只表达语义：红涨、绿跌、灰色为旧行情或失败；其余文本为黑白灰两级（正文 / 弱化）。
- 数字等宽：行情数字、表格数值列、盘口、K 线坐标与图例使用 Cascadia Mono / Consolas（中文回退微软雅黑）。
- 图表、盘口、自选表、资讯和 F10 随主题切换，不再保留“浅色页面中嵌深色块”的拼贴。

全部颜色定义在 `fincept-qt/src/screens/ashare/AShareTheme.h` 的 `theme::palette()`；新界面从这里取色，不硬编码。

## 布局

- 顶部单行终端条：品牌、指数行情条（单行点位与涨跌幅）、指数选择与 +/−、快捷键提示、主题、暂停、刷新。
- 左侧自选：搜索、分组、可排序可选列的表格。
- 右侧：报价行（名称代码 + 等宽价格、涨跌额、涨跌幅），两行明细，图表控制，K 线与五档 / 分笔并排；
  下方指标条与资讯 / F10 页签，可用分隔条拖动高度。

## 快捷键

作用范围限定在看板内部（`Qt::WidgetWithChildrenShortcut`），不影响完整工作台中的其他面板。

- Ctrl+K：聚焦股票搜索。
- Ctrl+1 … Ctrl+8：分时、日 K、周 K、月 K、5 / 15 / 30 / 60 分钟。
- F5：立即刷新。

## 未做 / 限制

- 未实现真正的命令面板弹窗；Ctrl+K 目前聚焦左侧搜索框，选中候选会加入自选。
- 未内置 JetBrains Mono 等字体文件，只使用 Windows 自带的 Cascadia Mono / Consolas。
- 偏好中已保存「日间」的用户启动后仍为日间；只有未保存过主题时才默认夜间。
