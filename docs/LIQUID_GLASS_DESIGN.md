# Liquid Glass 界面方向

## 当前视觉基线：浅色优先，支持日夜切换

用户明确否定了原先偏蓝、厚重边框的深色玻璃外观，指定苹果式白色背景，并要求日间/夜间切换。
默认使用日间主题；右上角主题选择即时生效，通过本地 `appearance` 设置保存，不清空自选或切换当前标的。
日间使用近白底、白色半透明表层、低对比边缘和克制的蓝色选中态。夜间使用中性炭灰，避免蓝紫强渐变和厚重高光。
延续用户要求：K 线绘图区与行情数字保持原样；现有深色行情表和图表阅读底层保留。

已查阅的苹果官方资料：
- https://developer.apple.com/videos/play/wwdc2025/219/
- https://developer.apple.com/design/human-interface-guidelines/materials
- https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/

采用其中控件/导航与内容分层、轻盈材质和浅深色适应的设计原则。
此 Windows Qt 实现为视觉适配，未实现苹果原生材质的动态折射、形变或系统背景模糊。

## 初步落地方向（待对齐参考图）

- 导航、顶部指数卡片、工具栏、弹出菜单采用统一的玻璃材质视觉语言。
- 圆角、边缘高光、透明层次、阴影和交互状态以共享参数及组件实现，避免各模块独立硬编码。
- K 线绘图区、报价数字和密集表格保持稳定、高对比的阅读底层；不要对文字与蜡烛图本身施加模糊或折射。
- 涨跌使用既有红涨绿跌规则，同时保留正负号和文字，不只依赖颜色传达状态。
- 选中、悬停、键盘焦点、加载、失效及禁用状态均须可辨识。
- 动效轻量，不因每次行情刷新触发持续闪烁；保留减少动效和减少透明度的实现空间。
- 高 DPI、窗口缩放、长名称、候选列表、横向滚动的指数栏都纳入视觉验证。

## 实现边界

当前项目为 C++20 / Qt Widgets。样式方向本身不授权迁移到 Web、Electron 或 Qt Quick。
背景模糊、折射和窗口材质需在目标 Windows/Qt 环境中单独验证；不能把半透明底色宣称为真实背景模糊。
性能不足或相关系统效果不可用时，使用可读的实色/半透明降级样式。
